# AI-Orchestrator quickstart

Run `ai-orchestrator status`, then `ai-orchestrator doctor --check readiness`. For CHUNSA, simulate an explicit TaskSpec before `task submit`; automated writers return an artifact that must pass gates and be accepted explicitly.

Harness is loopback-only at `127.0.0.1:3080` and starts only from a promoted immutable slot that has passed compatibility and security validation.
